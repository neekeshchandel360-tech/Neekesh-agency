# Project Architecture - Neekesh Agency

## 1. Tech Stack
- **Frontend:** Pure HTML5, Semantic Elements.
- **Styling:** CSS3 (Modern Flexbox/Grid, fluid typography using clamp, Custom CSS Variables).
- **Interactions:** Vanilla JavaScript (Intersection Observer API for scroll animations, LocalStorage for Cookie Banner).
- **Hosting:** Netlify (Automated CI/CD from GitHub Repository).

## 3. Deployment Flow
- GitHub Repository serves as the single source of truth.
- Direct connection to Netlify for absolute automated zero-configuration builds.
