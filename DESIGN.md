# Design System - Neekesh Agency

## 1. Visual Style
- **Aesthetic:** High-End, Ultra-Modern Dark Tech & Luxury Design.
- **Layout:** Clean typography, glassmorphism card components, fluid spacing, and subtle ambient glows.

## 2. Color Palette
- **Background:** Deep Obsidian Black (#030303 to #09090b) for an elite enterprise look.
- **Primary Accent:** Electric Royal Blue (#1e40af) with smooth Cyan/Neon Blue glows (#0ea5e9) for high-impact CTA focus.
- **Typography:** Crisp White (#ffffff) for prominent headings, and Soft Ice Gray (#cbd5e1) for premium readability in body copy.
- **Borders/Dividers:** Semi-transparent dark blue/grey tints (rgba(30, 64, 175, 0.15)).

## 3. Typography & Fonts
- **Headings & Logo:** Plus Jakarta Sans / Syne (Imported via Google Fonts, Weight: 750+, tight letter-spacing: -0.05em).
- **Body & Links:** Inter (Clean readability, mobile-first responsive layout optimization).

## 4. UI/UX Elements
- Smooth scale-up (translateY) and hover shadows on interactive CTA buttons.
- Fully responsive responsive navigation structure optimized for mobile displays.
